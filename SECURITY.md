# Security policy

## Supported versions

There is no released or security-supported version yet. Security fixes are
made on the current main branch while the 1.0 release roadmap is underway.
After 1.0, this file will list supported release lines and response windows.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could compromise a
Wayland session, expose clipboard or input data, bypass screen locking, or run
commands unexpectedly. Send a private report to:

`schmidt.l.samuel@gmail.com`

Include the affected revision, backend, reproduction steps, expected impact,
and whether the report may be acknowledged publicly. Do not include secrets,
clipboard contents, or unrelated logs. You should receive an acknowledgement
within seven days; this is a best-effort promise from a single maintainer, not
a guaranteed service level.
