(remove-split!)

Removes the current frame; its sibling absorbs the freed space and becomes current. Any windows the removed frame held are handed to the surviving sibling (into its first leaf, if the sibling is itself a subtree) so removing a frame never drops a window. A no-op if the current frame is the whole tree (nothing to remove).
